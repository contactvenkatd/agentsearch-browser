AgentSearch — a Chromium fork built from source

A browser with its own identity, private search, and native agent workflow. It is not Electron and not a wrapper: AgentSearch is a real Chromium fork.

Features

A focused browser stack

AgentSearch is a solo developer portfolio project exploring what agentic browsing looks like when it is integrated into the browser itself.

Custom new-tab dashboard

A purpose-built Chromium WebUI surface for search, account state, and agent controls.

Self-hosted search

A SearXNG backend keeps the default search path under your control.

Native AI sidebar

An integrated agent interface powered by the xAI Grok API.

Autonomous browsing

Chrome DevTools Protocol automation for navigation, form filling, and checkout flows.

Real Google sign-in

OAuth account access through credentials you register for your own build.

How it is built

Browser-native where it matters

Chromium on ARM64 Mac

The browser is compiled from Chromium source with AgentSearch changes applied directly.

Node.js agent bridge

A local service connects to the browser over the Chrome DevTools Protocol.

SearXNG

A private, self-hosted metasearch instance serves new-tab searches.

xAI Grok

The bridge sends grounded browser observations to Grok and executes validated actions.

Build from source

AgentSearch currently targets ARM64 Macs. Binary releases are not provided.
